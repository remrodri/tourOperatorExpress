# Roadmap de specs

El backend se corrige mediante specs pequeñas, no mediante un refactor total sin
límites.

| Spec | Objetivo | Estado |
|---|---|---|
| 001 | Contención de seguridad y baseline verificable | Draft |
| 002 | Autenticación, sesiones y autorización por rol/propiedad | Pendiente |
| 003 | Recuperación de contraseña segura | Pendiente |
| 004 | Ciclo de vida de archivos locales y acceso privado | Pendiente |
| 005 | Integridad de datos, índices y transacciones | Pendiente |
| 006 | Validación, errores y contrato HTTP | Pendiente |
| 007 | Cobertura, observabilidad y operación | Pendiente |

Cada directorio de spec contiene `spec.md`, `plan.md` y `tasks.md`. Solo una spec
`Ready` puede entrar en implementación y solo se implementa una tarea por vez.
